# SilverFox releases

Installers and update packages for [SilverFox](https://github.com/Rex-22/SilverFox), a cross-platform Doom launcher.

Download from [Releases](https://github.com/Rex-22/SIlverFox-release/releases/latest):

| Platform | File |
|----------|------|
| Windows | `SilverFox-win-Setup.exe` |
| macOS (Apple silicon) | `SilverFox-osx-arm64-Setup.pkg` |
| macOS (Intel) | `SilverFox-osx-x64-Setup.pkg` |
| Linux | `SilverFox.AppImage` |

Installed copies update themselves from this repo (Settings → Updates). Builds are not code-signed yet: Windows SmartScreen warns, and macOS blocks the first start until you allow it under System Settings → Privacy & Security.

This repo is written by the release workflow. Don't commit here by hand.
